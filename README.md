# aashishadhikari.com

Personal portfolio website of Aashish Adhikari — Software Engineer, AI/ML enthusiast, and MS applicant from Kathmandu, Nepal.

## Built With

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Vercel

## Features

- CMS-powered projects and certifications 
- Scroll-driven SVG journey line animation
- Editorial design system with Playfair Display + Space Mono typography
- Fully responsive — mobile to 4K


## Local Development
```bash
npm install
npm run dev
```
